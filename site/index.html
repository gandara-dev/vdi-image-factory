VDI Image Factory Create golden image

    Image

    Name and version the golden image and point to the Windows 11 installation media.

    Used for the build VM and the output folder, for example vdi-win11-finance.
    Written to the image manifest, for example 2026.09.1.
    Index inside install.wim. Check it with dism /Get-WimInfo.
    Installation media optional here

    Leave these empty to pass them to Packer at build time. The ISO never leaves your Hyper-V host.

    Build VM

    The temporary Hyper-V VM that Packer creates to install Windows. It is deleted after the image is exported, so its size does not decide the size of your desktops.

    The disk every desktop in the catalog gets.
    Needs internet access for WinGet. Generation 2 with Secure Boot is always used.

    Language and region

    Applied by the unattended answer file during Windows setup. The display language must exist in your ISO.

    Applications

    Pick a starting profile, then tick or untick single applications. Everything installs silently with WinGet for all users.

    Citrix Optimizer

    Citrix Optimizer removes Windows features and services a pooled desktop does not need. The build runs it only if you staged the official engine in the guest.

    AutoSelect picks the template for the installed Windows build.

    Machine catalog

    Machine Creation Services clones the image into desktops. Their names, domain, and OU come from here, not from the image.
