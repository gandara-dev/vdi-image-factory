4Applications

Start from one or more profiles, then add or remove individual packages. Everything installs silently with WinGet in machine scope.

5Citrix Optimizer

Runs only when the official Citrix Optimizer engine has been staged in the guest.

6MCS machine catalog

Machine names, domain, and OU are not baked into the golden image. Machine Creation Services creates the computer accounts from this identity pool and applies them to every machine it provisions.
